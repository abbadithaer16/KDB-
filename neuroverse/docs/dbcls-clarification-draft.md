Dear BodyParts3D team,

We would like to use BodyParts3D brain models in an educational, interactive 3D presentation
that may also be shown commercially as a portfolio piece. Before we do, we would be grateful
for a clarification of the licence.

Your licence page (https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html, last updated
2025/02/27) and the README for the latest release
(https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/README_e.html) state that the
database is licensed under Creative Commons Attribution 4.0 International.

However, the header of each OBJ file in `isa_BP3D_4.0_obj_99.zip` (release 4.0,
SHA-256 40665852c49f218326590e204db91064a1ecfc3c6f8cbd7bbbcaac62c7cd409e) states that the data
is licensed under Creative Commons Attribution-Share Alike 2.1 Japan.

Could you please confirm:

1. Does CC BY 4.0 apply to the release 4.0 polygon files, superseding the CC BY-SA 2.1 Japan
   text in their headers?
2. Does CC BY 4.0 also apply to the earlier releases still in your archive, for example
   release 3.0 (`20110915`)?
3. Is the following credit appropriate for adapted models (merged, simplified and compressed
   for web delivery)?
   "Brain model adapted from BodyParts3D, © The Database Center for Life Science, licensed
   under CC Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/)."

Thank you for making this resource available.
